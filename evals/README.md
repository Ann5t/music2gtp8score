# 参考谱评测集

4 首带参考答案的歌曲（**用户本人耳扒的鼓谱**，Guitar Pro 7 `.gp`，内嵌参考音频）：

| 歌曲 | 小节 | 音符数 | 速度 |
|---|---|---|---|
| 郭源潮 | 147 | 1445 | 82 |
| 大石碎胸口 | 242 | 2909 | 106 |
| 杀死那个石家庄人 | 170 | 2213 | 100 |
| 我等你们在崇明海边 | 60 | 618 | ~86 |

> 重要前提（用户原话）：「我扒的鼓谱只是我觉得是这样」—— 这些谱是个人解读，
> 不是绝对标准答案。评测分数衡量的是**与参考者口味的吻合度**，这正是本项目
> 的目标风格，而不是客观真理。

## 数据位置（版权原因不进仓库）

- 解析后的 `score.json`（alphaTab 全量模型）：`../Score/extracted/<歌名>/score.json`
- 内嵌音频：`../Score/extracted/<歌名>/backing.{mp3,wav}`
- 管线跑出的 53 轨：`out/<歌名>/stems/<音频名>/`

## 用法

```bash
python evals/eval_vs_gt.py --stems out/郭源潮/stems/guoyuanchao \
    --gt "../Score/extracted/郭源潮/score.json"
```

指标：在 (小节, 16 分音符槽, 粗鼓件类) 层面算 F1，槽位容差 ±1，小节偏移 ±2 搜索。

## 后续用途

- **风格挖掘**：排版偏好已从这些谱实证（两声部、每行 4 小节、隐藏力度等）
- **ML 训练对**：(MSST 分轨音频, 参考谱) 配对，可做转谱模型微调数据（约 25 分钟素材）
- **回归测试**：每次改转谱/量化逻辑后跑一遍 4 首，防止指标倒退
